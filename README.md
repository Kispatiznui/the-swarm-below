# THE SWARM BELOW

A dark action-survival game by **Kispat Dreams Interactive**.

**Alpha 0.3 — Playable Prototype**

THE SWARM BELOW is an action-survival experience where you fight, survive and descend into an increasingly hostile environment.

## Play the Alpha

**Play THE SWARM BELOW directly in your browser:**

https://kispatiznui.github.io/the-swarm-below/

No installation required.

## Controls

| Key                        | Action         |
| -------------------------- | -------------- |
| WASD                       | Move           |
| Mouse                      | Aim / interact |
| Left Mouse Button          | Attack         |
| E                          | Use / interact |
| Q / R / other ability keys | Abilities      |

## Current Prototype

Alpha 0.3 currently includes:

* Player movement
* Combat
* Enemy swarm
* Abilities
* Upgrade system
* HUD
* Survival gameplay
* Main menu
* Run-based progression
* Death and restart system

This is an early prototype and the game is still under development.

## About

The deeper you go, the harder it becomes to survive.

THE SWARM BELOW is being developed as an independent project by **Kispat Dreams Interactive**.
